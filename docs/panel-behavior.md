# 面板收起与重新打开

点击桌面或其他窗口，面板收起；点击托盘重新打开。右上角关闭也收起面板，不退出进程。饮水提醒、同步、当日记录和未提交的表单继续保留。

旧版在打开后的两秒内直接忽略失焦事件，也没有在宽限期结束后补查，快速点击外部时可能一直留在屏幕上。现在改为短暂去抖后确认失焦，不丢弃这段时间的动作；重新获得焦点时取消待执行的收起。

Windows 桌面激活还出现过前台窗口已经改变、Electron 未发出失焦事件的情况。Windows 版除观察窗口消息外，随软件提供一个 4.6 KB 的本地观察器 `desktop/native/PanelFocusObserver.exe`：

- 只在面板可见期间观察系统前台窗口和左右鼠标按钮状态、当前指针是否在面板矩形外，不安装输入钩子、不记录键盘、点击历史或健康数据，不访问网络。
- 真实外部鼠标点击能触发收起；内部点击保留面板，拥有者属于面板的模态窗口也保留。
- 收起即终止观察器；每次显示使用新的实例，过期实例的通知被忽略，避免旧通知误关新打开的面板。观察器也会在目标窗口销毁时退出。

源码同目录。需要重新生成二进制时，在 Windows 运行 `scripts/build-panel-observer.ps1`，使用系统已有的 .NET Framework 编译器；运行软件不要求安装编译工具。打包时须将该 exe 作为可执行的外部文件随附，不能仅放进不可执行的 asar 内。

相关系统语义来自 [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window) 与 [Windows WM_ACTIVATEAPP](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-activateapp)。实际行为以项目中的本机验证为准。

`npm run test:panel` 使用独立临时数据，覆盖连续两次立即转移焦点、系统前台切换后的真实外部指针点击、内部点击、关闭后托盘仍在、重新打开及记录不变。外部指针测试只点击临时创建的空白测试窗口，并恢复原指针位置。完整 UI 检查还通过实际控件坐标点开「修改」和「记一杯」，覆盖杯量、水位、翻牌、缩放和保存失败恢复。
