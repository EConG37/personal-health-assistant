## B. 15处文字残留

逐项处理（路径见复验表）：

1. 蛋白血压：删除"钠166mg/100g"→"蛋白本身钠不高（具体数值待核）"。
2. 牡蛎血压：删除"约270mg/100g"→"贝类钠含量因品种/加工差异大（未获条目），限量"。
3. 芹菜血压：删除"约80mg/100g"→"在蔬菜中相对偏高（具体数值待核）"。
4. 鳕鱼血脂：删除"脂肪仅0.5g/100g"→"生与烤形态不同、未保留数值；低脂水产蛋白"。
5. 面条血压：删除"一碗面可含盐2g以上"→"挂面常加盐，干基钠看标签；弃汤"。
6. 橄榄油血脂：删除"SFA约14%"→"以单不饱和脂肪为主（比例未核实）"。
7. 蜂蜜血糖：删除"约80%为糖"→"以糖为主（具体组成待核）"。
8. 可乐一般人群：删除"一瓶500ml已超50g糖"→"糖含量以标签为准；避免日常饮用"。
9. 西瓜血糖：删除"单次≤200g时GL有限"→"按个体化份量、计入总能量；不做GL数值判断"。
10-11. 核桃/杏仁血脂：删除"每日10～15g"→"单品用量无指南依据，按总能量安排"。
12. 啤酒血压：删除"500ml接近上限"→"按标签酒精度折算，不提供体积换算"。
13. 白酒血压：删除"约62ml"→"按标签酒精度折算，不提供毫升换算"。
14. 食盐血糖：删除"每日≤5g"→"清淡少盐，具体限量按合并疾病管理"。
15. 食盐血脂：同上。

另同步清理了复验未列但同类的残留：莲藕"碳水11.5g"、生抽"5ml约330mg钠"、甘薯"钾337mg"、豆干"钠可达数百mg"、绿茶"嘌呤1mg/100g"（该形态嘌呤已因体积口径置空）、羊肉串"223mg"的跨食品引用、卷心菜/洋葱/小白菜三处畸形句。

## C. 9个weight标签逐项依据

| 食材 | r3→r4 | 独立依据（非能量值） |
|---|---|---|
| 全麦面包 | limit→compatible | 全谷物主食，肥胖指南鼓励全谷物占谷物一半，替代精白米面；主食定量 |
| 燕麦 | limit→compatible | 全谷物；主食定量、不加糖 |
| 干紫菜 | limit→compatible | 干制海藻作汤/配菜少量；蔬菜充足方向；碘注意 |
| 沙丁鱼 | limit→compatible | 鱼类；肥胖指南优先低脂动物性食物（瘦肉/去皮禽肉/鱼虾），替代红肉 |
| 凤尾鱼 | compatible（r3）→**limit**（r4） | 加工水产罐头高盐高油；肥胖指南要求少选加工食品 |
| 小鱼干 | compatible（r3）→**limit**（r4） | 干制加工水产高盐；少选加工食品 |
| 干香菇 | limit→compatible | 菌藻类蔬菜，泡发后作蔬菜；少量 |
| 食盐 | limit→compatible（r3）→**limit**（r4） | 肥胖指南食盐≤5g；体重管理意义在限盐，不由能量决定；份量恢复"每日≤5g" |
| 玉米淀粉 | limit→compatible（r3）→**limit**（r4） | 纯碳水化合物（定义性），勾芡计入主食碳水 |

**额外调整**：酱油weight改为limit（高钠调味品，按标签折算）；猪肝/鸭肝/腰花weight改为`not_specifically_addressed`（肥胖指南未涉及内脏单品）；牡蛎/扇贝weight改为`not_specifically_addressed`（指南未单列贝类）；鳕鱼weight改为compatible（鱼类优先蛋白）。

**默认模板改造**：删除"未获得能量值→compatible"的统一逻辑。现按类别给依据：
- 蔬菜→"蔬菜≥500g框架"；水果→"水果总量+计入总能量"；蛋白类→"优先低脂动物性食物/豆制品"；主食→"主食定量、全谷物一半"；白水/茶/咖啡→"替代含糖饮料"。
- 每类均引用肥胖指南对应条款，标签不再由"缺能量"自动产生。

最终weight分布：compatible 66、limit 16、not_specifically_addressed 5、avoid 2（含糖饮料/果汁）。
