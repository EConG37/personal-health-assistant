# 菜名与配图核对

0.1.1 修复了按主要食材复用图片造成的菜名错配。鸡蛋饼曾显示玉米，馒头/花卷曾显示面条，紫薯饭/南瓜饭曾只显示薯块/南瓜，炒菜只显示单一肉片或蔬菜。

现在按独立 recipeId 查找已核对的菜品图，不再按 foodId、食材类别或关键词猜图。未知菜品使用中性餐盖。已有选择保留，升级后使用当前配图。

- 共核对 99 项：63 张新生成的成品菜图，33 项沿用外观匹配的奶、水果、蒸煮食物等图片，3 项使用原料与外观相同的菜品图。
- 例：鸡蛋饼是切块金黄葱花饼，玉米面馒头是黄色馒头，花卷是黄白卷形，玉米饭是米饭加玉米粒，山药鸡蛋面是面条加山药和鸡蛋。
- 原图通过内置 image_gen 生成；使用透明底、白色陶瓷餐具、现有三分之四俯视风格。每组 3×3 图集，逐格核对后使用。没有用代码绘制或拼造菜品照片。
- 七份原始 PNG 及 1x/2x WebP 保存于 `desktop/ui/assets/dish-*-v1.*`，不依赖联网取图。
- 完整提示词规格见 `specs.json`，99 项对应表见 `mapping-audit.json`，由 `scripts/build-dish-art-registry.js` 生成。WebP 与 CSS 由 `scripts/build-food-art.js` 编码生成；原图保留。

图为菜品示意，具体配料和做法以文字及实际制作时核对为准。
