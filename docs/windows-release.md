# Windows 打包与隐私检查

运行 `npm run release:win` 生成 Windows x64 安装版、自解压免安装 EXE 和文件夹免安装 ZIP，检查分发内容，并将成品、说明、报告及校验值放到 `release/0.1.2/`。也可依次运行 `npm run dist:win`、`npm run test:release`、`python scripts/build-portable-zip.py`、`node scripts/finalize-release.js`。不分发整个源码或构建目录。

ZIP 需完整解压再启动 `HealthCompanion.exe`；构建脚本核对压缩包的每项文件与原目录哈希，并实际运行解压后的程序完成独立数据自检。免安装 EXE 则在启动时自行解压。启用自启后，两种形式都需要保持所在位置稳定。

## 发布范围

打包配置使用明确的文件清单：核心模块、99 项指南菜品数据、桌面程序、页面、字体、图片和窗口焦点辅助程序。排除健康记录、飞书凭据、研究交付、截图、测试数据、调试日志、环境变量文件、构建脚本及开发依赖。

`audit-release.js` 检查待打包源码和最终 `app.asar` 内的每个文件、解包的辅助程序及两个 EXE 的可见字节。它会用本机目录、用户名、现有飞书连接字段、健康记录文件与加密凭据文件作本地比对；报告只保存结果、相对文件名和发布文件的校验值，不保存用于比对的个人信息。不解密现有飞书密钥。

运行包不包含第三方 npm 运行依赖；Electron 运行内核固定为 45.2.1。npm 构建工具链的独立告警不等同于成品运行依赖；不为消除告警强制降级最新版打包器。

## 数据去向

- 新用户默认没有健康记录、飞书凭据或连接的表格，默认关闭同步。
- 记录在当前 Windows 用户的应用数据目录中；应用升级继续使用原目录。饮水和健康记录为本地 JSON，并未对整个健康数据库加密。
- 飞书 App Secret 使用 Windows 用户绑定的系统安全存储加密，独立于健康记录，不返回页面，也不写进多维表格。既有 CLI 连接使用当前用户自己的已配置身份。
- 只有连接并开启飞书后，应用才把目标、健康档案和日记录同步到用户选择的表格。没有统计埋点或开发者的健康数据接收服务。
- 外卖需求由用户主动生成和复制，再由用户交给美团；应用不后台发送健康资料。

## 限制与验证

页面禁用 Node 集成并启用隔离和沙箱；敏感操作只接受本机主页面的请求。外部打开限于登记的指南来源和核对后的飞书地址；权限申请、嵌入外部网页与下载均默认拒绝。发布版关闭开发调试入口和 Node 环境变量调试开关，启用应用归档校验。

`--self-test` 使用独立临时目录、关闭同步、没有凭据，验证首次引导、记水与撤销、九张牌、确认、菜品来源、沙箱、图片/字体和原生辅助程序。验证后对比原用户记录及凭据，确认未被测试覆盖。它不连接个人飞书或发起订单。

本次检查针对分发内容及已实现的数据流，不构成完整渗透测试，也不承诺本地数据可抵抗拥有当前 Windows 用户权限的其他程序。当前 EXE 没有代码签名证书，Windows 可能显示未知发布者。

实现参考：[Electron 安全指南](https://www.electronjs.org/docs/latest/tutorial/security)、[electron-builder 配置](https://www.electron.build/configuration/)。
