# 源码同步与隐私检查

首次同步日期：2026-11-01。先以私有仓库完成源码与附件检查，同日经用户明确授权，在再次复核后转为公开仓库。

公开前复核覆盖源码、完整提交历史、发布说明及 15 份发布附件。GitHub 上的附件逐项比对 SHA-256，与本地通过检查的文件一致；实际健康记录、飞书连接和凭据仍只保存在使用者自己的设备及自行连接的表格内。

## 上传范围

上传程序源码、独立测试、构建脚本、本地图片和字体，以及不含个人资料的研究参考文档。安装包放在版本发布附件中，不纳入 Git 历史。

个人健康 JSON、飞书凭据、实际表格链接及资源编号、环境变量文件、机器配置、个人截图、日志、构建缓存和下载原文不上传。公开示例使用占位符；测试中的账号和密钥均为刻意构造的无效值，测试使用独立数据目录。

曾在 README、存储决策与 Agent 配置示例中发现实际飞书表格地址，已在首次提交前移除。没有把含这些地址的历史提交推送到 GitHub。Git 提交使用 GitHub 隐藏邮箱，不使用本机配置的私人邮箱。

## 后续同步前检查

暂存准备提交的文件后，运行：

```powershell
npm run audit:repository
npm run audit:source
```

前者逐个读取 Git 暂存区的实际内容，与本机用户名、目录、私人邮箱、现有连接字段、健康记录和加密凭据的本地指纹比对，同时检查常见密钥格式与敏感文件名。不会解密飞书凭据，结果仅输出相对文件名、类别和行号，不输出用于比对的值。报告保存在被忽略的 `dist/privacy-repository.json`。

首次同步另使用 Gitleaks 扫描提交内容与首次提交历史。安装包继续执行 Windows 归档隐私检查与 Mac ZIP 内部内容检查。检查用于发现常见泄露及本机已知信息，不保证检出任何形式的个人信息；新文档和新附件仍需按上传范围复核。

下载的研究原文和历史验收缓存只留在本机；仓库保留来源链接、页码及校验值。重建研究结果时，需先从记录的官方来源下载对应原文。日常使用、核心测试与打包不需要这些缓存。
