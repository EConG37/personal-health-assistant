# 指南菜品与用户喜好

当前版本按用户确认的新方向提供选菜参考，不做营养累计或固定克数配餐。此前 r1–r5 食材调研保留在 research-handoff 目录，未接入推荐计算，405 项缺失数值不再阻塞这个选菜流程。

## 本地数据

- `core/data/guide-dishes.json`：99 项真实菜品、主食、奶豆饮品和水果。包括 30 项蛋白类菜品、29 项蔬菜菜品、24 项主食、6 项奶豆饮品、10 项水果；不是 99 道完整正餐。
- `catalog-evidence.json`：每项的原菜名、原主要食材文字、来源 PDF 和页码。番茄炒蛋对应原名“西红柿炒鸡蛋”。其他菜名不由模型拼接生成。
- `source-files.json`：本地原文路径及文件校验值。来源为卫健委发布的高尿酸与痛风、肥胖（2024）、高血压、糖尿病、高脂血症（2023）食养指南。
- `extracted-candidates.json`：PDF 中提取的候选文字，仅供核查；推荐只读取经过筛选的本地菜品库。

运行 `node scripts/build-guide-dishes.js` 可重建菜品库；重建前需按来源链接下载对应 PDF 到 `source-files.json` 记录的位置，下载缓存不随源码上传。运行 `npm run test:dishes` 验证菜名出处、忌口、喜好和旧记录兼容，不需要下载原文。

## 推荐方式

1. 从指南已有的常见菜品中选菜，使用原文列出的主要食材，不自行生成“清炒番茄”这类菜名。
2. 按全部已知主要食材筛除不喜欢、过敏及素食冲突，包括不在菜名里的花生、鸡肉、小麦等。调味料、品牌配料和交叉接触仍须用户或商家确认。
3. 优先匹配喜欢的食材、相关目标的指南示例及喜欢的做法；保留九张翻牌、自主确认、已吃记录与外卖需求。
4. 只给少油少盐、酱汁另放、规律进餐等定性提示。菜品、餐次及每日记录不生成嘌呤、蛋白、热量、盐油或克数的估算。
5. 多种疾病同时存在时仅作日常选菜参考，不能据此声明一个组合满足所有疾病的治疗目标。尿酸目标的动物菜品另要求在痛风指南示例中出现。急性痛风及原先的特殊人群继续暂停通用菜单。

各菜来源可在详情页展开查看，并打开卫健委原文。**整餐是应用重组，不能称为卫健委原版整日食谱**。来源中的数字及证型未移入用户菜单；不自动判断中医证型。脂肪肝目标使用日常菜品参考与定性提示，尚无该目标专属的卫健委菜谱来源，不宣称专属治疗菜单。

旧版已选搭配需要重选，历史用餐和饮水记录原样保留；旧记录的克数不再用于计算。`core/foods.js` 的旧营养字段仅为原型遗留，当前推荐、忌口与记录汇总不读取。
