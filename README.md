# 日常 · 个人健康助手

一个常驻 Windows 托盘的桌面健康工具。用齿轮圆环记录每天的饮水，结合健康目标和饮食偏好搭配三餐，支持连接个人飞书多维表格。

## 使用

Windows 成品放在 `release/0.1.2/`：安装版可创建桌面快捷方式；免安装 ZIP 先解压整个文件夹，再打开 `HealthCompanion.exe`，请保留其余文件。另保留自解压启动的免安装 EXE。都不需要 Node.js；开启自启时请将解压后的文件夹或免安装 EXE 保留在固定位置。已有用户继续使用本机记录，新用户从首次引导开始。

开发和重新打包的说明见 [Windows 打包与隐私检查](docs/windows-release.md)。

源码同步范围与后续检查见 [GitHub 隐私检查](docs/github-privacy.md)。

```powershell
npm install
npm start
```

首次打开完成三步：选择目标 → 设置饮食喜好与禁忌 → 确认体重、作息和饮水目标。可同时选择降尿酸、稳血糖、控血压、调血脂、管理体重、改善脂肪肝，或先选择均衡饮食。之后在「我的设置」调整。

默认静默提醒：到提醒时间，托盘与首页圆环中央显示缓慢闪烁的红点，不推送系统消息。记水后停止红点，并暂缓一个提醒间隔；安静模式、休息时间、已达标或目标未确认时停止催促。「我的设置」可选择完整动效、轻柔动效或跟随系统，并预览 5 秒提醒。轻柔模式保留常亮红点。

「我的设置 → 我的杯子」可长期保存每杯容量（50–2000 ml），首页与托盘「记一杯 / 半杯」一起使用；重开仍保留。首页不再提供修改杯量的入口，避免误触。250 ml 为小圆杯、300 ml 为带把随行杯、500 ml 为运动水瓶，其他容量匹配接近的杯型。杯内水位表示**当天饮水量占每日目标的比例**，随记水、撤销和同步变化，到目标后封顶；不是现实杯内的剩余水。完整动效下记水有杯子回弹、水位升降与圆环过渡，翻牌保留翻转。

托盘保留圆环，已完成段比未完成轨道更粗，颜色按 Windows 任务栏明暗适配；任务栏与应用颜色分别设置时也会读取系统任务栏偏好。悬停显示完成百分比与「已喝 / 目标 ml」，提醒仅闪烁中央红点。

误记可撤销。未填写特殊情况时，饮水目标沿用旧版体重参考公式；特殊情况下应使用医生确认的量。

「好好吃饭」为早、午、晚餐各准备 9 张候选牌。翻开 → 查看菜品、主要食材和做法提醒 → 明确确认；选好不等于已吃过，另点「已吃，记下来」才记录。翻牌进度和选择按天保存；换一副保留已确认搭配。排除不喜欢、所选常见过敏原与不符合素食方式的食物，优先考虑喜欢的食物；候选不足时保留空位，不用禁忌食物凑数。推荐不再估算嘌呤、蛋白或固定克数；也不判定一天是否达到营养目标。

餐食配图覆盖全部 66 种可选食材，每种食材使用独立图片，包括肉鱼、豆制品、主食、蔬菜、奶类、水果及坚果饮品。牌面组合显示主菜和主食，详情使用独立菜品图。0.1.1 已逐项核对 99 项菜品，新增 63 张成品图，修正鸡蛋饼、馒头、花卷、杂粮饭及混合炒菜等错配；未知菜品使用中性图标。图片是食材示意，主要食材与做法以文字为准。素材随软件本地保存，可离线显示；食材旧数值不再用于当前推荐。

窗口宽度 400px，顶部标题和底部「今日 / 好好吃饭 / 我的设置」固定，只有中间内容滚动。点击桌面或其他窗口，面板自动收起；托盘、饮水提醒与同步继续运行，点击托盘即可再次打开。右上角关闭也只收起面板。

菜品库现含 99 项指南菜品、主食及加餐选择。详情中可展开查看菜品出处；整餐按偏好重新组合。数据来源与边界见 [指南菜品说明](docs/guide-dishes/README.md)。旧版已选搭配需重选，历史记录保留。

## 外卖需求

选好午餐、晚餐等搭配后，点「准备外卖需求」，填写预算、附近位置（可选）和备注。软件将所选菜品、做法要求与过敏原整理成文字，先预览再复制；可以同时打开[小美官网](https://xmei.meituan.com/)。在小美 App 粘贴发送，也可交给美团 App 底部的「小团」。选店、配料核实、地址、总价、下单与支付在美团确认。

当前实现是复制需求与打开官网，没有接入消费者 Agent 的自动发送或下单接口；官网主要提供 App 使用入口。调研依据和边界见文档。

## 数据与飞书

原数据目录保持 `%APPDATA%/uric-acid-companion/data.json`。JSON 原子写入；保存失败时回退内存状态，文件损坏时先保留 `.corrupt-<时间戳>` 副本。旧版本记录会保留，并补充新版引导。

飞书采用本地先保存、联网合并的方案。软件运行时每 5 分钟同步，也可手动同步。入口位于「我的设置」最上方，可查看状态、管理连接、打开表格、恢复档案或停止同步。

同一位置的「开始引导 / 查看指南」打开四步连接与使用页：准备普通表格 → 允许读写 → 填写连接 → 日常使用。分别说明自有应用与本机已有连接、信息复制位置、权限发布、手机累计补记与恢复操作。浏览指南不连接、不发起授权、不写云端；可以直接跳回对应表单，未提交的凭据信息会保留。

其他用户可以连接自己的普通多维表格：填写自己飞书应用的 App ID、App Secret、已有 Base 链接；在表格中添加文档应用并授予编辑权限，应用需开通多维表格读写权限（例如 `bitable:app`，不是创建 Base 应用模式）。软件直接调用飞书接口，不要求另装 CLI；仅在指定 Base 内建立「每日健康记录」表。密钥通过 Windows 系统加密后独立存放，不写入健康 JSON、云表或回传前端。

本机已有飞书连接的用户也可以复用 lark-cli，并沿用表格或新建专用 Base。两种连接都只对各自指定的表格操作；软件不内置开发者的连接或密钥。

在飞书对应日期行的「手机补记ml」填写当天手机补记累计总量，桌面下次同步会合并；不要直接改「饮水ml」来补记。档案并发修改时保留冲突，支持明确选择云端档案恢复。具体能力和边界见[调研与存储决策](docs/research-and-storage.md)。

每位用户连接自己的表格，同步表名为「每日健康记录」。表结构包含 10 个字段，支持档案读回及重复同步去重。重新打开桌面助手后沿用该用户本机保存的连接。平台初始的空表保留，不参与同步。

## 验证

```powershell
npm test          # 原核心逻辑检查
npm run test:health  # 多目标、禁忌、迁移、离线重试、同步去重与冲突
npm run test:interactions # 杯量、翻牌、选择合并、外卖文本与自有飞书连接模拟
npm run test:dishes       # 指南出处、全部主要食材忌口、喜好、主菜多样性与旧记录兼容
npm run test:cup-motion # 杯型、水位边界、提醒节奏和动效偏好
npm run test:food-art # 全部可选食材独立配图、主菜主食对应与未知食材回退
npm run test:tray # 托盘16/32px进度、深浅色对比和百分比提示
npm run test:panel # 真实鼠标外部点击后的自动收起、内部保留、托盘存活和重新打开
npm run test:ui   # 独立临时数据，验证真实桌面流程并保存截图
node scripts/verify-feishu.js  # 已连接后：读回真实档案，并验证相同数据不重复写入
```

UI 验证不修改实际健康记录，不发送消息或外卖订单。当前截图输出在 `.oil-ui/usability-polish/shots/`，覆盖食材配图目录、三种杯型、空/半/满水位、红点提醒、今日、翻牌、确认摘要、详情、外卖预览、飞书设置、360px、200% 完整滚动、减少动效与强制颜色。验证检查全部食材图片的实际加载、裁切定位、两档 WebP 与 PNG 回退；也检查完整动效覆盖系统减少动态偏好、真实回弹和翻牌动画、提醒预览超时与静音停止、真实使用的字体、键盘翻牌、保存失败恢复、选中标记与菜名不重叠。自有应用的网络交互使用模拟飞书接口测试，系统加密在真实 Electron 中检查。

```text
core/profile.js       目标目录、常见过敏原、特殊情况、设置校验与选材限制

core/feishu-app.js    自有飞书应用直连与系统加密凭据

core/reminders.js     提醒触发、持续与停止条件，动效偏好

desktop/main.js       托盘、窗口、提醒与受限 IPC

docs/                 调研证据与存储决策
```

没有前端构建步骤，保留原生 Electron 结构。Windows 面板附带一个小型本地观察器，仅在可见时补查外部点击，收起时终止；源码、重建方式及验证见 docs/panel-behavior.md。字体文件随软件提供，不依赖网络字体服务；当前采用用户确认的 A 方案：浅色画布、深色饮水仪表、青柠绿主操作、用户确认的 B 方案柔雾冰胶杯型（轻微右倾）和悬浮底部导航。主题在 `desktop/ui/style-a.css`，杯身使用本地半透明图集，独立动态水体在 `cups.js` / `cups.css`，功能基础样式保留在 `style.css`。本地食材素材按实际候选组合展示，来源与提示词见 `desktop/ui/assets/SOURCES.md`。

0.1.2 对引导、饮水、翻牌、详情、外卖、设置和飞书指南检查实际渲染字体，正文、数字与表单均为阿里巴巴普惠体 2.0。关闭及选中符号改用 SVG，避免调用其他系统字体。普通与中等字重的原始字体文件随包保留，无需用户安装字体。

## 当前范围

当前只提供指南菜品与做法方向，不估算营养或固定克数，也不判断能否达到治疗指标。整餐按用户偏好重组；脂肪肝目标尚无专属菜谱来源。指标目标和用药遵医嘱。肾功能异常、心衰/限水、孕哺期、未成年及急性痛风暂停通用配餐。

开发版开机自启仍受未打包环境限制。飞书手机端目前支持查看和累计补记饮水，不支持完整餐食编辑或任意字段双向同步。



Mac 的 M 系列和 Intel 试用包及构建边界见 [Mac 试用说明](docs/mac-release.md)。
